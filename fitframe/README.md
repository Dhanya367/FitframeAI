# FitFrame AI
Body-type detection and style recommendations (Flask + MediaPipe Pose + OpenCV + SQLite).

## Run
Windows: py -3.12 -m venv venv ; venv\Scripts\activate
Mac:     python3.12 -m venv venv ; source venv/bin/activate

pip install -r requirements.txt
python app.py   # open http://localhost:5000
